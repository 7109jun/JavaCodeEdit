Claude AI 코드 생성 (선택 확장 프로그램)
========================================

하는 일
  주석을 쓰고 그 줄 끝에서 Tab  -> Claude가 만든 코드가 미리보기로 뜹니다.
  한 번 더 Tab                  -> 주석 아래에 코드가 들어갑니다 (Ctrl+Z 한 번으로 되돌림).
  Esc / 마우스 클릭 / 글 입력 / 커서 이동 -> 취소됩니다.

  - // 줄이 여러 개 이어지면 하나의 설명으로 합쳐집니다. /* ... */ 와 /** ... */ 도 됩니다.
  - 커서가 주석 줄의 "맨 끝"에 있을 때만 동작합니다. 그 밖의 Tab은 평소와 똑같습니다.
  - 코드 뒤에 붙은 주석(int a; // ...)과 .java가 아닌 파일에서는 동작하지 않습니다.

설치 (한 번만)
  1) 편집기에서  확장 > 확장 프로그램 관리 > 확장 프로그램 추가 (jar)...  로 claude-ai.jar 선택
  2) 목록에서 "Claude AI 코드 생성"의 "사용"에 체크 (확인 창에서 '예')
  3) 새로 생긴 "Claude" 메뉴 > "API 키 설정..." 에서 Anthropic API 키(sk-ant-...) 입력
     (키는 https://console.anthropic.com 에서 발급. 환경변수 ANTHROPIC_API_KEY 도 쓸 수 있습니다)

  * 일부러 기본 확장 프로그램(extensions 폴더)에 넣지 않았습니다. 이 확장은 파일 내용을 인터넷으로
    보내므로, 첫 실행 때 다른 확장과 함께 자동으로 켜지지 않고 직접 켜야 합니다.

메뉴
  Claude > API 키 설정...   키 입력
  Claude > 모델 선택...     기본 claude-sonnet-5-5 (haiku-5-5: 가장 빠름, opus-5-5: 가장 똑똑하지만 느림)
  Claude > 사용 방법

주의할 점
  - 코드를 만들 때 현재 파일의 내용(커서 앞 약 24,000자 + 뒤 약 8,000자)이 Anthropic API로 전송됩니다.
    비밀번호/키가 들어 있는 파일에서는 쓰지 마세요. API 사용 요금이 발생합니다.
  - 키는 사용자 폴더의 .minijava-editor/claude-ai.properties 에 글자 그대로 저장됩니다
    (Linux/macOS는 나만 읽게 만듭니다). 원치 않으면 환경변수만 쓰세요.
  - 만들어진 코드는 틀릴 수 있습니다. 적용 전에 미리보기를 읽고, 적용 후 F6으로 오류 검사를 해 보세요.
  - import 줄은 추가하지 않습니다 (필요한 클래스는 전체 이름으로 씁니다).

고급 설정 (claude-ai.properties 를 직접 고칠 때)
  effort=low     응답 속도/깊이 조절 (low, medium, high ...). 비워 두면 보내지 않습니다.
                 "effort" 때문에 오류(HTTP 400)가 나는 모델을 쓸 때는 비우세요.
  실행할 때 -Dminijava.claude.endpoint=주소  로 API 주소를 바꿀 수 있습니다 (회사 게이트웨이용).

문제가 생기면
  - 팝업에 "HTTP 401" -> 키 확인 / "HTTP 404 ... model" -> 모델 ID 확인 / "연결하지 못했습니다" -> 네트워크, 프록시
  - 아무 반응이 없으면: 확장 프로그램이 "실행 중"인지, 커서가 주석 줄의 맨 끝인지 확인하세요.

다시 만들기 (JDK 21 필요)
  build.bat (Windows, 이 폴더의 상위에 jdk 폴더가 있으면 자동으로 씁니다) 또는 sh build.sh
